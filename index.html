체험관 회원·판매 관리 프로그램

안드로이드 휴대폰앱 설치 파일 받기 · 약 50MB PC (윈도우·맥)설치 없이 바로 쓰기

아이폰은 아직 지원하지 않습니다. 휴대폰과 PC는 같은 계정으로 로그인하면 같은 자료가 보입니다.

휴대폰 설치 방법

  1. 위의 [안드로이드 휴대폰]을 누릅니다.
  2. 다운로드가 끝나면 알림이나 다운로드 폴더에서 파일을 눌러 설치합니다.
  3. "안전하지 않은 앱" 같은 경고가 나와도 설정에 들어가지 말고, 세부정보 더보기 → 무시하고 설치를 누릅니다.
  4. 앱을 열고 회원가입합니다. 원장은 "체험관 새로 만들기", 직원은 원장에게 받은 6자리 초대 코드를 입력합니다.
카카오톡에서 눌렀는데 다운로드가 안 되면, 오른쪽 위 메뉴(⋮)에서 "다른 브라우저로 열기"를 누르세요.

PC에서 쓰기

위의 [PC (윈도우·맥)]를 누르고 휴대폰과 같은 이메일·비밀번호로 로그인합니다. 설치할 것은 없습니다. 주소를 즐겨찾기에 넣어 두면 편합니다. 30분 동안 쓰지 않으면 자동으로 로그아웃되고, 여러 사람이 쓰는 PC에서는 다 쓴 뒤 설정 → 로그아웃을 눌러 주세요.

이미 설치했다면

새 버전이 나오면 같은 버튼으로 받아 설치하면 됩니다(덮어 설치, 데이터는 그대로). 설치된 버전은 앱의 설정 맨 아래에서 볼 수 있습니다.
